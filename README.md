# TurfMate ⚽

TurfMate is a web application designed to make booking and managing football turfs simple and convenient.

## ✨ Features

- 🔐 User Authentication
- ⚽ Browse available turfs
- 📅 Book turf slots
- 💳 Easy booking management
- 📱 Responsive and user-friendly UI
- 🏟️ Turf and booking management

## 🛠️ Tech Stack

- React.js
- JavaScript
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
